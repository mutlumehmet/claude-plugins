# dev-workflow

Skills for shipping code with Claude Code. Part of [claude-plugins](../../README.md).

| Skill | What it does |
|---|---|
| [`watch-ci`](skills/watch-ci) | Watches a pull request, a merge or a commit until every check has finished, then reports GREEN or RED by itself |

## Install

```
/plugin marketplace add mutlumehmet/claude-plugins
/plugin install dev-workflow@mehmetmutlu
```
