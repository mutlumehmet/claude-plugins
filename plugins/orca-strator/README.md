# orca-strator

Renamed to **[`orca-fleet`](../orca-fleet)** on 27 October 2026, so the name says what it does (orchestrator, lanes, checkers and handovers). Part of **Orca Strator**.

This folder is an empty plugin kept for one version so that installed copies move over: updating `orca-strator` installs `orca-fleet` as a dependency and removes the old code. Then uninstall `orca-strator`:

```
/plugin install orca-fleet@mehmetmutlu
/plugin uninstall orca-strator@mehmetmutlu
```
