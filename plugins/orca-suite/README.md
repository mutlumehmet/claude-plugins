# orca-suite

Renamed to **[`orca-strator`](../orca-strator)** on 27 October 2026, so the install name matches the family name, Orca Strator.

This folder is an empty plugin kept for one version so that installed copies move over: updating `orca-suite` installs `orca-strator` as a dependency. Then uninstall `orca-suite`:

```
/plugin install orca-strator@mehmetmutlu
/plugin uninstall orca-suite@mehmetmutlu
```
