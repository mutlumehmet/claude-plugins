# Open items

Every item raised in any session lands here in the same turn it comes up, and leaves only when it
is done or the person drops it. Wrap ups and "what is left" answers are read from this file.
Every item a fleet takes on has a Done when list (3 to 8 checkable lines, agreed with the person,
separated by `;` or linked to its brief). It is done only when every line holds, measured now.

| Id | Raised | Item | Done when | Owner | State |
|---|---|---|---|---|---|
| <S-1> | <date, by whom> | <task, check, question or deferral> | <1. ...; 2. ...; 3. ... (or link to the brief)> | <session or person> | <open: lines 1, 3 hold / done: every line holds, how / dropped: by whom> |
