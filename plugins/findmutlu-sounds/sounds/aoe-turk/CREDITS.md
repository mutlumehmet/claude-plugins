Every clip comes from the openpeon pack "aoe2-villager-turkish-male" by Yusuf Kinatas (https://openpeon.com/packs/aoe2-villager-turkish-male, repository https://github.com/yusufkinatas/peon-ping-custom-packs, tag v1.0.1), converted to M4A (AAC, 128 kbps) because macOS afplay stops Ogg clips after about a second, and renamed; the source file column links the original Ogg.
