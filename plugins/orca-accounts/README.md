# orca-accounts

Renamed to **[`orca-quota`](../orca-quota)** on 27 October 2026, so the name says what it does (usage band, /quota and the warning before a limit). Part of **Orca Strator**.

This folder is an empty plugin kept for one version so that installed copies move over: updating `orca-accounts` installs `orca-quota` as a dependency and removes the old code. Then uninstall `orca-accounts`:

```
/plugin install orca-quota@mehmetmutlu
/plugin uninstall orca-accounts@mehmetmutlu
```
